PolySignal Research support

PolySignal Research is published by Kishore Shimikeri and is free to use.

For bug reports, documentation questions or feature requests, use GitHub Issues. A GitHub account may be needed to post. Start the issue title with PolySignal Research plugin.

Include the plugin version, Python version, operating system, the command or workflow attempted, and a small synthetic input that reproduces the problem. Describe expected and actual behavior. Exclude credentials, private trading data, personal identifiers and confidential logs from public reports.

Read the README for examples, methods for model assumptions and privacy policy for data handling. GitHub Issues is public support, not a private upload channel.
