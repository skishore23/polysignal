PolySignal Research privacy policy

Publisher: Kishore Shimikeri. Effective date: 2026-10-01.

This policy covers the free, offline PolySignal Research plugin and its bundled Python commands, not the separate PolySignal trading-research application.

Local processing

The bundled tools read the input files selected for a task and print calculation or verification results. They contain no network client, analytics, telemetry, publisher upload, account registration or credential collection. Research inputs and command results are not transmitted to the publisher by these tools. There is no publisher-operated research-data store for this version.

The agent host may create task files, retain conversations and command outputs, or process content using its own services. Your host's settings and privacy policy govern that processing. Offline Python execution does not imply that an agent conversation stays on your device. Manage or delete local inputs/results on your device and conversations through the host's controls.

Project website

The project website is hosted on GitHub Pages. It serves static pages, assets, precomputed synthetic scenarios and plugin downloads. Scenario controls select local precomputed results; this website has no analytics, tracking cookies, account form or publisher-operated upload endpoint. GitHub receives ordinary web requests when serving the site under its own privacy practices.

GitHub and support

The project uses GitHub Issues for support. If you choose to post, your GitHub identity and submitted content may be public and visible to the publisher and others. Use synthetic examples; do not post private trading data, credentials, personal identifiers or confidential logs. Support content is used to understand and respond to the reported issue.

GitHub handles browsing, account data and issue storage under its own privacy statement. Use GitHub's controls to manage your posts and account data. Requests about an existing project issue can refer to its issue number without repeating private content. This plugin does not impose a separate automatic support-post deletion schedule or operate a separate upload service.

Questions

Use project support for questions about this plugin's data behavior. Do not include sensitive information in public support requests.
